# Anmeldung und Benutzerkonto

Dieses Kapitel erklärt, wie Sie sich bei Pfarrplaner anmelden, Ihr Passwort verwalten und sich wieder abmelden.

Pfarrplaner ist nicht öffentlich zugänglich wie eine normale Website. Sie benötigen ein persönliches Konto, damit sichtbar ist, wer welche Gottesdienste, Dienste oder Daten bearbeiten darf.

---

## Benutzerkonto

Für die Nutzung von Pfarrplaner benötigen Sie ein persönliches Benutzerkonto. Dieses wird von Ihrem Administrator eingerichtet. Eine eigene Registrierung ist nicht möglich.

Ihr Administrator legt Ihr Konto an und weist Ihnen die nötigen Rechte zu. Die Zugangsdaten kommen danach automatisch per E-Mail. Nach der ersten Anmeldung müssen Sie das Anfangspasswort ändern, bevor Sie normal weiterarbeiten.

---

## Anmelden

Wenn Sie die Adresse von Pfarrplaner in Ihrem Browser aufrufen, erscheint zunächst die Anmeldeseite.

### So melden Sie sich an:

1. Für die Anmeldung mit einem Passkey klicken Sie direkt auf **Mit Passkey anmelden**. Sie müssen dafür keine E-Mail-Adresse eingeben.
2. Für die Anmeldung per E-Mail tragen Sie Ihre Konto-Adresse in das Feld unterhalb des Passkey-Buttons ein und klicken auf **Anmeldelink per E-Mail erhalten**.
3. Prüfen Sie Ihr Postfach und gegebenenfalls den Spam-Ordner auf eine E-Mail mit dem Anmeldelink. Wenn Sie eine andere Adresse verwenden möchten, wählen Sie auf der Anmeldeseite **Mit einer anderen E-Mail-Adresse anmelden**.
4. Öffnen Sie den Link aus der E-Mail und wählen Sie auf der angezeigten Bestätigungsseite **Jetzt anmelden**.

Die Anmeldeseite enthält diese Elemente:

- **E-Mailadresse**: Ihr Benutzername für Pfarrplaner.
- **Mit Passkey anmelden**: Lässt Sie Ihre Identität mit einem Passkey bestätigen, zum Beispiel mit Geräte-PIN oder Fingerabdruck.
- **Anmeldelink per E-Mail erhalten**: Sendet einen zehn Minuten gültigen Link an die eingegebene Adresse.
- **Prüfe dein Postfach**: Nach der Anforderung erklärt eine Bestätigung, wo Sie den Anmeldelink finden und wie Sie die Anmeldung abschließen. Dort können Sie auch eine andere E-Mail-Adresse eingeben.
- **Hinweis zur Unterstützung**: Unter dem Formular finden Sie einen kurzen Hinweis mit Links für eine einmalige oder regelmäßige freiwillige Unterstützung des Projekts.

Passkeys funktionieren nur über eine sichere HTTPS-Verbindung. Falls Ihr
Browser oder Gerät die Passkey-Anmeldung nicht unterstützt, können Sie den
Anmeldelink per E-Mail verwenden.

Nach erfolgreicher Anmeldung werden Sie zu der Startansicht weitergeleitet,
die für Ihr Konto eingestellt ist. Häufig ist das die
[Startseite](startseite.md), manchmal auch direkt der [Kalender](kalender.md)
oder ein anderes Modul.

Wenn Sie die Zwei-Faktor-Authentifizierung eingerichtet haben, erscheint nach
der Bestätigung des Anmeldelinks eine zusätzliche Codeabfrage. Geben Sie den
sechsstelligen Code Ihrer Authenticator-App in die einzelnen Ziffernfelder ein
oder fügen Sie den vollständigen Code ein. Alternativ können Sie einen
Recovery-Code im Textfeld eingeben. Jeder Recovery-Code funktioniert nur
einmal. Die Zwei-Faktor-Abfrage läuft nach fünf Minuten ab. Danach fordern Sie
einen neuen Anmeldelink an.

Wenn Ihre Administration eine wichtige Mitteilung hinterlegt hat, erscheint direkt nach der Anmeldung zusätzlich ein Hinweisfenster über der eigentlichen Seite. So können Änderungen angekündigt werden, die alle Benutzerinnen und Benutzer oder nur bestimmte Gruppen betreffen.

Das Hinweisfenster enthält diese Schaltflächen:

- **Später**: Blendet den Hinweis für die aktuelle Anmeldung aus. Nach einer späteren neuen Anmeldung kann er erneut erscheinen.
- **Nicht wieder anzeigen**: Versteckt diesen Hinweis dauerhaft für Ihr Benutzerkonto.

> **Tipp:** Schützen Sie Ihr Gerät mit einer Bildschirmsperre und melden Sie sich auf gemeinsam genutzten Computern nach der Nutzung ab.

---

## Passwort vergessen

Auf der aktuellen Anmeldeseite gibt es keinen eigenen Link **Passwort vergessen?**. Wenn Sie Ihr Passwort nicht mehr wissen, wenden Sie sich bitte an eine Administratorin oder einen Administrator. Diese Person kann in der Benutzerverwaltung ein neues Passwort setzen oder Sie zum Ändern Ihres Passworts auffordern.

---

## Passwort ändern

Sie können Ihr Passwort jederzeit selbst ändern.

1. Klicken Sie oben rechts auf Ihren **Namen** (oder das Benutzersymbol).
2. Klicken Sie im Menü auf **Einstellungen**.
3. Öffnen Sie den Reiter **Sicherheit**.
4. Geben Sie Ihr aktuelles Passwort ein.
5. Geben Sie das neue Passwort ein und wiederholen Sie es zur Bestätigung.
6. Klicken Sie oben links auf **Speichern**.

> **Hinweis:** Ihr neues Passwort muss mindestens 8 Zeichen lang sein und mindestens je einen Großbuchstaben, Kleinbuchstaben, eine Zahl und ein Sonderzeichen enthalten.

Wenn Ihr Konto mit einem vorläufigen Anfangspasswort eingerichtet wurde, führt Pfarrplaner Sie nach der Anmeldung zuerst zum Passwortwechsel. Erst nach erfolgreichem Wechsel können Sie die übrige Anwendung nutzen.

Das vorläufige Anfangspasswort erhalten Sie von Ihrer Administration. Es ist nur für die erste Anmeldung bestimmt und muss danach sofort durch ein eigenes starkes Passwort ersetzt werden.

Während dieser erzwungenen Änderung sind die übrigen Seiten von Pfarrplaner gesperrt. Auch wenn Sie eine andere Adresse direkt aufrufen, gelangen Sie wieder zum Passwortwechsel. Abmelden bleibt jederzeit möglich.

---

## Abmelden

Es ist wichtig, sich abzumelden, wenn Sie Pfarrplaner nicht mehr nutzen – besonders auf gemeinsam genutzten Computern.

1. Klicken Sie oben rechts auf Ihren **Namen**.
2. Klicken Sie im Dropdown-Menü auf **Abmelden**.

Sie werden dann zurück zur Anmeldeseite weitergeleitet.

---

## Konto gesperrt oder Probleme beim Anmelden?

Wenn Sie sich trotz richtigem Passwort nicht anmelden können, wenden Sie sich bitte an Ihren Administrator. Dieser kann Ihr Konto prüfen, entsperren oder ein neues Passwort setzen.
